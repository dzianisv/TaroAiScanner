### Recording gotchas (cost ~4 attempts; see .agents/cua-tests/record_demo.py)
- The emulator is a CONTENDED resource. A parallel agent killed and relaunched `agentpod_e2e`
  mid-run. Only ONE AVD exists on this box; launch with `-read-only` to coexist.
- After a cold boot the emulator throws a "System UI isn't responding" ANR and load avg hits 8.
  Dismiss it and wait for load < ~3 before recording, or every uiautomator dump misses.
- screenrecord at native 1080x2400 under load captured 67 frames over 112s (unusable slideshow).
  `--size 720x1600 --bit-rate 4000000` gave 475 frames / 73s.
- screenrecord's tail is lost if you SIGINT right after the target screen appears: the first good
  run reported "reading rendered: True" yet the finished mp4 ended back on the camera screen.
  Dwell ~15s on the result (scroll it) and sleep ~8s after SIGINT before `adb pull`.
- ALWAYS verify with `ffmpeg -sseof -N` tail frames + read them as images. Duration/size/exit code
  all lied here.
- The app keeps a persistent guest session, so onboarding usually does NOT appear. A loose /Guest/
  regex matches the "Guest Seeker" dashboard profile row and taps the wrong element — match
  "Continue as Guest" in full.
- "Scan Physical Card" is below the fold; scroll-until-found beats one fixed-distance swipe.

### Emulator gotchas (taro_demo, port 5560)
- `svc wifi disable` / `cmd connectivity airplane-mode enable` **kills this
  emulator**. Do not use for failure injection. Repoint the app's saved proxy
  at `https://127.0.0.1:9` instead (https, not http — http trips Android's
  cleartext policy and you get a policy error, not a connection failure).
- Patching Room DB via `run-as`: you MUST `PRAGMA wal_checkpoint(TRUNCATE)`
  and delete the on-device `-wal`/`-shm`. Pushing a stale `-wal` back silently
  reverts the edit on next open — cost ~40min of false results.
- `emulator ... &` from a tool call gets killed when the call ends; no `setsid`
  on macOS. Launch as `( nohup emulator ... </dev/null >log 2>&1 & )`.
- `taro_driver.cold_start()`'s 6s wait is too short on a cold-booted emulator;
  poll `focused_package() == PKG` first or every lookup MISSes.
- Building a worktree needs `local.properties`, `app/google-services.json` and
  `debug.keystore` copied in — none are tracked.
- `env -u GH_TOKEN gh ...` required; stale GH_TOKEN shadows keyring auth.
